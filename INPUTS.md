# Starter build

This is the first Godot 4 project scaffold for AFTERLIGHT: THE LAST GROUND.

## Current foundation
- Godot 4 project configuration using the mobile-friendly Compatibility renderer
- A simple test ground and survivor capsule
- Basic walking, running and jumping
- First-person / third-person camera switching

## Temporary desktop test controls
The input actions still need to be added in **Project > Project Settings > Input Map**:

| Action | Key |
| --- | --- |
| move_forward | W |
| move_back | S |
| move_left | A |
| move_right | D |
| run | Shift |
| jump | Space |
| switch_camera | C |

## Important
This is a starter scaffold, not a finished game and not yet tested in the Godot editor. The next step is to validate the project in Godot, add touch controls for Android, and then begin building the first small environment.
